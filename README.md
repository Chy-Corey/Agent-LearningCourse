# Agent-LearningCourse

构建一个 AI Agent 有点像组装一台智能机器人，你需要给它大脑（LLM）、手脚（Tool）以及操作手册（skill）。网络上可以搜索到的React、MCP、LangChain 正好对应了它的思考方式、连接标准以及开发框架。

为了能够系统性地掌握 Agent 开发，需要把这些概念串联起来，从最基础的“零部件”讲起，再讲“思维逻辑”，最后落实到“开发工具”和“学习计划”。

### 一、核心组件（Agent 的“手脚”与“说明书”）

在这一阶段，我们主要解决“Agent 能做什么”以及“如何教会它做”的问题。

#### 1. Tool

这是 Agent 的**“手脚”**。

- **定义**：大模型本身只是一个“大脑”，它无法直接获取实时天气、无法操作 Excel、也无法查询数据库。Tool 就是赋予它这些能力的函数或 API。
- **作用**：弥补大模型“四体不勤、五谷不分”的缺陷（即无法获取实时信息、无法执行具体操作）。
- **例子**：一个搜索天气的 API、一个计算器函数、一个发送邮件的脚本。

#### 2. Skill

这是 Agent 的**“操作手册”或“肌肉记忆”**。

- **定义**：Skill 是对 Agent 能力的标准化描述。它通常是一个文档（如 Markdown 文件），详细规定了 Agent 在特定任务下的**任务规则、执行步骤、输出格式**。
- 结构：
  - **元数据**：名称、描述。
  - **指令库**：目标、执行步骤、判断规则、输出格式。
- **关系**：Skill 往往定义了 Agent **何时**以及**如何**调用 Tool。比如一个“旅行规划 Skill”可能会规定：“先调用‘搜索机票 Tool’，再调用‘预订酒店 Tool’”。

> **小结**：**Tool** 是原子能力（能干什么），**Skill** 是组合策略（怎么干、按什么顺序干）。

### 二、行为逻辑（Agent 的“大脑回路”）

有了手脚和手册，Agent 还需要一个“思考机制”来决定下一步做什么。这就是 **ReAct**。

#### 3. ReAct

这是一种**“思维框架”**，全称为 **Reasoning + Acting**。

- **原理**：它让大模型在输出最终答案之前，先进行“思考”，然后决定“行动”，观察行动的结果，再继续思考。
- 流程循环：
  1. **思考**：用户问“今天北京天气如何？” -> 模型想：“我需要查询今天的天气数据。”
  2. **行动**：模型调用 `get_weather(location="Beijing")` Tool。
  3. **观察**：系统返回“25°C，晴”。
  4. **思考**：模型想：“我已经有了数据，可以回答用户了。”
  5. **最终回答**：“今天北京天气晴朗，气温 25°C。”
- **意义**：这是目前 Agent 最主流的工作模式，它让模型能够解决复杂问题，而不是仅靠“直觉”瞎猜。

### 三、连接标准与框架（Agent 的“神经系统”与“工厂”）

当 Agent 变得越来越复杂，我们需要标准接口来连接各种工具，也需要框架来简化开发。

#### 4. MCP

这是 Agent 领域的**“USB-C 接口标准”**。

- **全称**：Model Context Protocol（模型上下文协议）。
- **痛点**：以前，如果你想让 Claude 连接本地数据库，你要写一套代码；想让它连接 Slack，又要写一套。每个平台和每个工具之间的连接方式都不一样，非常混乱。
- 作用：MCP 定义了一套统一的协议。
  - **对开发者**：你只要按照 MCP 标准写一个 Tool，它就能被所有支持 MCP 的客户端（如 Claude Desktop）直接使用。
  - **类比**：就像手机充电口统一成了 Type-C，不管你是什么牌子的手机（Agent），也不管是什么牌子的充电器（Tool），插上就能用。
- **地位**：它是连接大模型与数据源/工具层的通用协议。

#### 5. LangChain

这是 Agent 开发的**“脚手架”**。

- **定义**：一个开源的开发框架，提供了一整套工具、库和接口，帮助开发者快速构建基于大模型的应用。
- 包含内容：
  - **Chains**：把多个步骤串起来（比如先总结文档，再翻译）。
  - **Agents**：内置了 ReAct 等逻辑，让你不用从零写提示词。
  - **Integrations**：集成了成千上万的 Tool（Google Search, SQL, Python REPL 等）。
- **关系**：LangChain 里可以封装 Skill，调用 Tool，实现 ReAct 逻辑，甚至支持 MCP 协议。它是把上述所有概念落地的代码载体。

### 四、学习流程

#### 1. 标准化与连接（理解“接口”）

- 目标：掌握 MCP，理解如何标准化地连接LLM。
- 学习内容：
  - MCP 协议：阅读 Anthropic 的 MCP 官方文档，理解 Client-Host-Server 架构。
  - ****MCP** Server 开发**：尝试写一个简单的 MCP Server（例如连接本地 SQLite 数据库）。
  - 动手实践：配置 LLM 连接你写的 MCP Server，直接在对话框里调用Tool。

#### 2. 记忆**系统（Memory）**

- 目标：掌握如何设计、实现Agent的记忆能力。

- 学习内容：
  - 概念：短期记忆（对话窗口）、长期记忆（向量数据库、markdown存储）、记忆检索 / 更新 / 清理；
  - 技术：`FAISS/Chroma/Pinecone`、`LlamaIndex`索引。

#### 3. 思维方式（理解“流程”）

- 目标：掌握 ReAct 模式，让 Agent 能解决多步问题。
- 学习内容：
  - 概念：任务分解、子任务排序、状态跟踪、结果评估、自我修正
  - 技术：ReAct 论文/原理：阅读相关博客，理解“观察-思考-行动”循环。

#### 4. 综合实战（借助框架构建完整 Agent）

- 目标：整合 Skill、Tool、ReAct，构建一个可用的 Agent。
- 学习内容：
  - **LangChain 入门**：安装 LangChain，学习 `LangChain Agents` 模块。
  - **动手实践**：使用 LangChain 构建一个“数学助教”，它能调用计算器 Tool 解决复杂的数学应用题（例如：先算乘法，再算加法）。
